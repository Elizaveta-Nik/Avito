
# Инструкция по запуску автоматизированных тестов

## Требования

Перед началом работы убедитесь, что у вас установлены следующие компоненты:

- **Java 17**
- **Maven**
- **Selenium WebDriver**
- **ChromeDriver** (или другой драйвер для браузера)

## Установка

Следуйте этим шагам для установки и настройки проекта:

1. **Клонируйте репозиторий:**
   ```bash
   git clone <URL>
   cd <repository>
   ```

2. **Проверьте, что у вас установлен Maven:**
   ```bash
   mvn -v
   ```

3. **Установите зависимости:**
   ```bash
   mvn install
   ```

## Запуск тестов

Для запуска автоматизированных тестов выполните следующие шаги:

1. **Запустите тесты с помощью Maven:**
   ```bash
   mvn test
   ```

2. **Проверьте результаты:**
   Убедитесь, что все тесты прошли успешно.
