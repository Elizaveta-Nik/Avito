# Сообщения об ошибках

## 1. Возможность указания отрицательной стоимости товара
**Описание:** При создании товара и указании стоимости можно указать отрицательное число (например, -14 рублей).
**Шаги воспроизведения:**
1. Открыть форму создания товара.
2. Ввести название товара.
3. В поле стоимости ввести отрицательное число (например, -14 рублей), работает и скроллом колесика мыши.
4. Нажать кнопку "Создать".

**Ожидаемый результат:** Должно быть отображено сообщение об ошибке, указывающее на недопустимость отрицательной стоимости товара.
**Фактический результат:** Товар создается с отрицательной стоимостью.

## 2. Отсутствие сообщения об успешном создании товара
**Описание:** Нет сообщения об успешном создании товара.
**Шаги воспроизведения:**
1. Открыть форму создания товара.
2. Ввести название и стоимость товара.
3. Нажать кнопку "Создать".

**Ожидаемый результат:** Должно быть отображено сообщение об успешном создании товара.
**Фактический результат:** Сообщение об успешном создании товара отсутствует.

## 3. Ошибка JavaScript при открытии вкладки с сайтом
**Описание:** При открытии вкладки с сайтом появляется ошибка JavaScript.
**Шаги воспроизведения:**
1. Открыть браузер и перейти на сайт.
2. Открыть любую вкладку на сайте.

**Ожидаемый результат:** Вкладка открывается без ошибок.
**Фактический результат:** Появляется ошибка JavaScript.
